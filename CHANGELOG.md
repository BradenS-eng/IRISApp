# Changelog

## v1.1.0 - 2026-09-07

### Added

- Inverse one-dimensional fin-model fitting for effective in-plane thermal conductivity from extracted IR temperature profiles.
- Configurable fit parameters, boundary mode, profile side, and optional fixed pixel window.
- A synthetic regression test for recovery of the known inverse-model conductivity.

### Fixed

- Corrected inverse profile extraction and prevented lateral-profile axis-label cropping.

### Documentation

- Documented the inverse-model assumptions, configuration, and interpretation in the README.
